# 🚀 Projeto Web II - Sistema de Cadastro de Amigos e Login

Este repositório contém o projeto final desenvolvido para a disciplina de **Programação Web II**, apresentado aos professores como parte da avaliação da matéria. O sistema consiste em uma aplicação web completa com autenticação de usuários (Login) e um painel de gerenciamento de cadastros (CRUD).

## 📋 Funcionalidades
- **Sistema de Login:** Tela de autenticação para acesso seguro ao sistema.
- **Gerenciamento de Amigos (CRUD):**
  - **Create:** Cadastro de novos amigos com informações de contato.
  - **Read:** Listagem e visualização dos amigos cadastrados.
  - **Update:** Edição de dados de amigos já existentes.
  - **Delete:** Remoção de registros do sistema.
